# 🎓 AI Resume Analyzer

An AI-powered resume analysis and placement assistant built for college students.

## 🚀 Live Demo

[Open AI Resume Analyzer](https://ai-resume-analyzer-9updtdcbpgzayo6xpkufqk.streamlit.app/)

## 📌 Project Status

**Completed ✅**

## ✨ Features

* 📄 Upload resume in PDF format
* 🔍 Extract resume text
* 🧠 Detect technical skills
* 📊 Calculate ATS score
* 🎯 Compare resume with job descriptions
* 📈 Calculate job match score
* 🤖 Generate AI-powered resume feedback
* 💡 Suggest missing skills
* 📥 Download resume analysis report
* 🎓 Student-focused placement dashboard

## 🛠️ Technologies Used

* Python
* Streamlit
* Groq AI
* PyPDF2
* Matplotlib

## 🧩 How It Works

1. Upload a resume PDF.
2. Paste the target job description.
3. The application extracts and analyzes the resume.
4. Skills are detected automatically.
5. ATS and job-match scores are calculated.
6. Groq AI generates personalized feedback.
7. The user can download the analysis report.
